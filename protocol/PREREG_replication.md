関連: `rocuronium_MRGPRX2/docs/PREREG_independent_seeds.md`（同じ誤りの訂正）

## なぜ複製するか

レターの計算は yakuri3（Intel Core i7-13700F）単独で行われており、
プラットフォーム混在はない。しかし以下の2つの問題が後から判明した。

### 問題1：「四つの独立 run」は独立ではなかった

本文の記述:

> Across **four independent runs** the seed-to-seed range is 0.006 for MMMA
> and 1.30 for compound 48/80, so both outcomes are reproducible.

該当 run の `iniseed` は **917（既定）/ 1000 / 2000 / 3000**、`sampling = 10000`。
HADDOCK3 は `seed = iniseed + idx`（idx = 1..sampling）でシードを配るため、
各 run が使う乱数シードの集合は `{iniseed+1 .. iniseed+10000}` となり、

| ペア | 重複率 |
|---|---|
| 917 vs 1000 | **99.2%** |
| 917 vs 2000 | 89.2% |
| 917 vs 3000 | 79.2% |

**最も離れたペアでも 79% を共有している。**
したがって range 0.006 は「独立サンプリングのばらつき」ではなく
「ほぼ同一サンプリングの再現性」であり、**この一文は書き換えが必要**。

### 問題2：`ncores` が run 間で不均一

| run | ncores |
|---|---|
| `MMT_blind`（MMA + WT） | 16 |
| `MMT_D184N_blind`（MMA + D184N） | **6** |
| `Compound4880_blind` | 16 |
| `Compound4880_D184N_blind` | 16 |

**中心的主張の差分計算が `ncores` 境界を跨いでいる**
（MMA 側は 16→6、compound 48/80 側は 16 内）。
`iniseed` の配り方から理屈では `ncores` 非依存だが、別途検証中（遺伝研 Job 20532477）。
本複製では **全 run を `ncores = 16` に統一**してこの交絡を構造的に除く。

## 判定基準（結果を見る前に固定。動かさない）

レターの中心的主張は**非対称性**である：

> compound 48/80 は D184 の負電荷を失うと大きく損をするが、MMA は損をしない。

各条件について、5 独立反復の rank-1 cluster スコアの**中央値**と**range**を求め、

- ΔC = median(C48/80 + D184N) − median(C48/80 + WT)
- ΔM = median(MMA + D184N) − median(MMA + WT)

（スコアは負が良いので、Δ > 0 が「損をした」）

**非対称性が確認されたと判定する条件（3つすべてを満たすこと）:**

1. **ΔC > 0**（compound 48/80 は損をする）
2. **ΔC ≥ 5 × |ΔM|**（MMA の変化は compound 48/80 の 1/5 未満）
3. ΔC が、両条件の反復 range の和より大きい（反復ノイズで説明できない）

**確認されなかった場合:**

- 条件2を満たさない → **非対称性の主張を弱める**。「MMA は損をしない」ではなく
  実測された Δ とその range をそのまま報告する
- 条件3を満たさない → **D184N の効果自体を主張しない**
- **移行コストや原稿の完成度を理由に基準を緩めない**

### 本文の記述で必ず直すこと（結果によらず）

1. **「four independent runs」を削除**し、独立反復（重複 0%）で測り直した
   range を報告する。**旧 range 0.006 / 1.30 は「同一サンプリング空間内の
   再現性」として、そう明記した上で補足に置く**
2. **−0.24 という単一値の代わりに、5 反復の中央値と range を報告する**
   （プラットフォーム間変動が score で 0.302 単位あり、−0.24 より大きいため、
   単一値で「lost nothing」を支える構図を避ける）
3. **HADDOCK3 2025.11.0 / CNS 1.3 patch U / 静的リンク（SHA-256 `ce6b0c6b…`）/
   CPU 型番 / `ncores` / `iniseed` の配り方**を Methods 相当部に記載する
4. D184A・E164A の記述（「MMA lost 0.82 units (4.3%)」等）も同様に
   中央値 + range に置き換える

### プラットフォーム間比較として報告できること

12 run（`ncores = 16` を使っていたもの）は yakuri3 と遺伝研で `ncores` が一致するため、
**CPU のみを変えた比較**になる。ロクロニウム側で測った値（WT で距離 0.05–0.06 Å、
score 0.302 単位 = 0.51%、rigidbody アンサンブルの 32% が入れ替わる）が
MMA 系でも同程度かを確認し、Methods に実測値として記載する。

「同一サンプリング空間内での再現性」および
